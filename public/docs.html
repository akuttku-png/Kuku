receotp API

API RESTful untuk pembelian nomor OTP & nomor Telegram siap-pakai. Semua respons berupa JSON.

Base URL

https://receotp.my.id
Semua contoh di halaman ini pakai base URL di atas.

Autentikasi

Setiap request ke endpoint /api/* wajib membawa API key lewat header x-api-key, atau via query ?apikey=. Ambil key lo lewat bot Telegram kami: kirim command /apikey.

curl https://receotp.my.id/api/balance \
  -H "x-api-key: jm_xxx"
const res = await fetch("https://receotp.my.id/api/balance", {
  headers: { "x-api-key": "jm_xxx" }
});
const data = await res.json();
import requests
r = requests.get(
  "https://receotp.my.id/api/balance",
  headers={"x-api-key": "jm_xxx"}
)
data = r.json()
Jaga kerahasiaan API key. Jangan pernah share atau embed di client-side app. Kalau bocor, generate ulang lewat command /apikey di bot.

Kode Error

Semua error response berformat sama:

{
  "ok": false,
  "error": "NO_SALDO",
  "message": "Saldo kamu tidak cukup."
}

409NO_STOKStok habis
409OTP_NOT_RECEIVEDBelum ada kode, tidak bisa retry/finish
502UPSTREAM_ERROR / ORDER_FAILEDGagal menghubungi provider
GET/api/balance

Cek saldo untuk API key ini. Saldo ini sama dengan saldo bot Telegram kamu.

curl https://receotp.my.id/api/balance \
  -H "x-api-key: jm_xxx"

Response 200

{ "ok": true, "saldo": 15000 }
GET/api/countries

Daftar semua negara yang didukung untuk order OTP.

curl https://receotp.my.id/api/countries \
  -H "x-api-key: jm_xxx"

Response 200

{
  "ok": true,
  "countries": [
    { "id": 6, "name": "Indonesia", "iso": "id" }
  ]
}
GET/api/services

Daftar layanan (WhatsApp, Facebook, dst) beserta harga & stok untuk negara tertentu. Harga sudah termasuk markup kami.

NamaTipeWajibKeterangan
countrystringYaISO negara (mis. id) atau ID numerik
 
curl "https://receotp.my.id/api/services?country=id" \
  -H "x-api-key: jm_xxx"

Response 200

{
  "ok": true,
  "services": [
    { "code": "wa", "name": "Whatsapp", "price": 4477, "stock": 8162 }
  ]
}
POST/api/order

Buat order OTP baru. Saldo dipotong saat itu juga. Kalau order gagal / stok habis, saldo otomatis dikembalikan.

NamaWajibKeterangan
countryYaISO atau ID negara
serviceYaService code (mis. wa, fb)
 
curl -X POST https://receotp.my.id/api/order \
  -H "x-api-key: jm_xxx" \
  -H "Content-Type: application/json" \
  -d '{"country":"id","service":"wa"}'

Response 200

{
  "ok": true,
  "activationId": "1234567890",
  "phone": "+6281234567890",
  "service": "wa",
  "country": "id",
  "price": 4477,
  "saldoSisa": 10523
}
Order auto-expire 15 menit kalau OTP tidak diterima. Saldo otomatis di-refund.
GET/api/status/:activationId

Cek status order & ambil kode OTP. Poll setiap ~5 detik.

curl https://receotp.my.id/api/status/1234567890 \
  -H "x-api-key: jm_xxx"

Response 200 — OTP diterima

{
  "ok": true,
  "state": "sukses",
  "hasOtp": true,
  "otp": "123456"
}
StateArti
waitingMenunggu OTP masuk
suksesOTP diterima
cancelOrder dibatalkan (saldo di-refund otomatis)
expiredOrder sudah expired 15 menit
POST/api/retry-code

Minta kode OTP baru untuk nomor yang sama (setelah kode pertama sudah diterima).

NamaWajibKeterangan
activationIdYaID order dari /api/order
 
curl -X POST https://receotp.my.id/api/retry-code \
  -H "x-api-key: jm_xxx" \
  -H "Content-Type: application/json" \
  -d '{"activationId":"1234567890"}'
POST/api/finish

Tandai order selesai setelah selesai pakai kode.

NamaWajibKeterangan
activationIdYaID order
 
curl -X POST https://receotp.my.id/api/finish \
  -H "x-api-key: jm_xxx" \
  -H "Content-Type: application/json" \
  -d '{"activationId":"1234567890"}'
POST/api/cancel

Batalkan order & refund saldo. Hanya boleh kalau belum menerima OTP.

NamaWajibKeterangan
activationIdYaID order
 
curl -X POST https://receotp.my.id/api/cancel \
  -H "x-api-key: jm_xxx" \
  -H "Content-Type: application/json" \
  -d '{"activationId":"1234567890"}'

Response 200

{
  "ok": true,
  "activationId": "1234567890",
  "refunded": 4477,
  "saldoSisa": 15000
}

Telegram — Nomor Siap Pakai

Endpoint khusus untuk beli nomor Telegram yang sudah login.

GET/api/telegram/countries

Daftar negara Telegram yang tersedia beserta harga & stok.

curl https://receotp.my.id/api/telegram/countries \
  -H "x-api-key: jm_xxx"

Response 200

{
  "ok": true,
  "countries": [
    { "code": "US", "name": "US", "flag": "🇺🇸", "price": 11500, "stock": 19 }
  ]
}
POST/api/telegram/order

Beli 1 nomor Telegram. Saldo langsung dipotong sesuai harga negara itu.

NamaWajibKeterangan
countryYaCountry code, mis. US, ID, GB
 
curl -X POST https://receotp.my.id/api/telegram/order \
  -H "x-api-key: jm_xxx" \
  -H "Content-Type: application/json" \
  -d '{"country":"US"}'

Response 200

{
  "ok": true,
  "orderId": "tg_a1b2c3d4e5f6a7b8",
  "phone": "+12025550100",
  "country": "US",
  "price": 11500,
  "saldoSisa": 5000
}
Simpan orderId. Panggil /api/telegram/code saat Telegram kirim OTP.
POST/api/telegram/code

Ambil kode login Telegram. Bisa dipanggil kapan saja selama order belum di-release.

NamaWajibKeterangan
orderIdYaID order dari /api/telegram/order
 
curl -X POST https://receotp.my.id/api/telegram/code \
  -H "x-api-key: jm_xxx" \
  -H "Content-Type: application/json" \
  -d '{"orderId":"tg_a1b2c3d4e5f6a7b8"}'

Response 200 — Kode diterima

{
  "ok": true,
  "orderId": "tg_a1b2c3d4e5f6a7b8",
  "state": "ok",
  "phone": "+12025550100",
  "code": "12345"
}
POST/api/telegram/release

Notifikasi "saya sudah selesai pakai nomor ini". Setelah release, nomor tidak bisa diakses lagi via /api/telegram/code.

NamaWajibKeterangan
orderIdYaID order
 
curl -X POST https://receotp.my.id/api/telegram/release \
  -H "x-api-key: jm_xxx" \
  -H "Content-Type: application/json" \
  -d '{"orderId":"tg_a1b2c3d4e5f6a7b8"}'
GET/api/telegram/orders

List semua order Telegram aktif milik API key ini (belum di-release).

curl https://receotp.my.id/api/telegram/orders \
  -H "x-api-key: jm_xxx"
